# fixtures — 출처 표기

이 디렉터리의 응답 fixture는 **③ 스키마 유도 — [실측 캡처 아님]** 이다.

실제 Groq API 응답을 캡처한 것이 아니라, 이 저장소가 소유한 `src/app/api/chat/route.ts`의
응답 계약(상태코드 · 본문 형태)에서 유도했다. 따라서 —

- **상류 계약 drift를 구조적으로 잡지 못한다.** Groq 응답 형태가 바뀌어도 이 fixture는 그대로다.
- **mock 통과는 연동 검증이 아니다.** 실제 연동 확인은 `@e2e-live` 수동 실행뿐이다.

`chat.post.500.json`의 `error` 값은 실제 문구가 아니라 **패스스루 검증용 센티넬**이다 —
useChat이 서버 메시지를 그대로 전달하는지 보기 위한 것이며, 문구 자체를 기대값으로 쓰지 않는다.
